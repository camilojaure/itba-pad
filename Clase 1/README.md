# Clase 1 — El mapa: datos, Python y el mundo fintech

**Tipo:** Teórica introductoria | **Duración:** 3 horas

## Objetivo
Que el alumno salga con el mapa mental claro: qué es el análisis de datos, por qué Python, cómo funciona la IA como copiloto, y cómo se inserta todo esto en su trabajo en finanzas.

## Contenido
- El ciclo del dato a la decisión
- Línea de tiempo: de R + RStudio hasta Claude Code
- Google Colab como entorno de trabajo
- Vibe Coding: programar con IA como copiloto
- Demo en vivo de análisis completo (sin que los alumnos codeen)
- Configuración de cuentas y primer notebook

## Materiales
| Archivo | Descripción |
|---------|-------------|
| `Clase_1_Intro.ipynb` | Notebook con la demo y el contenido de la clase |

## Dataset
No se requiere dataset externo. La clase usa datos de ejemplo embebidos en el notebook.

## Para el docente
Esta clase NO es de código — es de contexto y motivación. El objetivo es que salgan con ganas de volver la semana siguiente. La demo en vivo es el corazón: mostrás en 10 minutos lo que van a poder hacer al final del curso.
